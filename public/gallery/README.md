# Chess World Gallery Photos Folder

Place your uploaded photo files (JPG, JPEG, PNG, WEBP) directly inside this `/public/gallery` folder!

### Standard Filenames (Template):
- `photo1.jpg` — Founding Mentor & Dr. Sai (1994)
- `photo2.jpg` — State Championship Trophy Presentation (1998)
- `photo3.jpg` — Academy Mentors on Heritage Swing (1996)
- `photo4.jpg` — Chennai District Championship Award (2001)
- `photo5.jpg` — India Map Shield Trophy Presentation (2003)
- `photo6.jpg` — Chess World Academy Champions (2005)

### How to use in code:
You can reference any file placed in this folder as `/gallery/your-filename.jpg` in `src/data/historicGalleryPhotos.ts` or through the Gallery UI upload tool!
